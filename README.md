# 💎 finance-aditya (Adit Financial Suite PRO VIP)

Dashboard Manajemen Finansial Pribadi & Brankas Kas Cerdas berbasis HTML, CSS Glassmorphism, Tailwind CSS, JavaScript, dan Firebase Realtime Database.

## ✨ Fitur Utama
- 🔐 **Multi-Layer Security:**
  - Login modal PIN aman dengan proteksi hashing SHA-256 (Maks 10 Karakter).
  - Virtual Touch Keypad responsif untuk mobile dan laptop.
  - Auto-Lock inaktivitas dengan timer hitung mundur langsung.
  - Pemulihan sesi & ganti PIN terlindungi dengan Master Secret Code.
  - Brute-Force Shield otomatis mengunci 30 detik setelah 3 kali gagal.
- 👁️ **Stealth Mode (Privacy Mask):** Samarkan nominal saldo saat berada di tempat umum secara instan.
- 🎯 **Target Finansial & Tabungan Impian:** Buat rencana tabungan impian, setoran (+ Nabung), penarikan (- Tarik), dan progress bar visual.
- 🔄 **3 Jenis Transaksi:** Pemasukan, Pengeluaran, dan Mutasi / Transfer antar dompet & rekening bank.
- ⚡ **Smart Fast Parser:** Pencatatan cepat berbasis teks instan multi-line (`+gaji 5jt`, `-makan 50k cash`, `mutasi bni dana 100k`).
- 📊 **Visualisasi Chart.js:** Grafik analitik perbandingan rasio kas dan distribusi pengeluaran per kategori.
- 📁 **Export Laporan:** Unduh riwayat rekonsiliasi kas langsung ke format CSV/Excel.
- 📱 **Desain Super Responsif:** Tampilan modern Dark Luxury Glassmorphism yang mulus di HP, Tablet, dan Laptop.

## 🚀 Menjalankan Aplikasi
Buka file `money.html` langsung di browser, atau deploy langsung ke Vercel / GitHub Pages.
